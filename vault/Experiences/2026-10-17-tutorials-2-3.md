# 직원 배치와 비상상황 교육을 마친 경험

이 기록은 Codex가 별도 저장 프로필의 실제 게임에서 수행한 플레이를 요약한다.
다른 모델이 읽을 때에는 이전 플레이어에게서 전달받은 경험이다. 자신의 직접 경험이나 모델 학습 결과로 표현하지 않는다.
행동 전 이유는 공개된 의사결정 설명이며 내부 사고 과정의 복원은 아니다.

## 목표와 결과

튜토리얼 2·3을 사람의 게임 조작 도움 없이 완료했다. 원본 저장 파일 29개, PlayerPrefs,
원본 PlayerSettings의 무변경을 실행 전·행동 전·완료 후 확인했다.

직원 배치 교육에서는 연구 제안서를 드래그해 제출하고, 조슈아를 용기 II로 고용했다.
남은 LOB으로 지혜 II를 강화한 뒤 지휘팀에 배치했다. 올리버·제미니아노·조슈아 모두에게
교육용 무기와 방어구를 장착했다. 게임이 다음 튜토리얼 진행 확인창을 표시했다.

비상상황 교육에서는 교육용 오뚜기 토끼에 억압 작업을 시키라는 지시를 따랐다.
이는 교육에서 카운터 감소와 탈출을 보여 주기 위한 실습이며, 일반 관리 전략으로 추천한 행동이 아니다.
탈출한 토끼의 RED 공격·WHITE 약점과 직원 장비를 화면에서 확인해 제압을 지시했다.
에바 한 명 이후 교육 요청에 따라 타샤와 헌터를 드래그 선택하고 우클릭으로 합류시켰다.
제압 후 이동, 헌터의 패닉 회복, 소집 호출을 수행했다.
마지막에 게임이 **“이상으로 관리자 교육이 완료되었습니다”**라고 표시했다.

## 판단과 시행착오

- 연구·직원 카드 드래그와 장착은 UI 안내와 실제 화면 좌표를 근거로 진행했다.
- 제압 목록의 속성 아이콘/초상화 클릭은 명령 시작으로 이어지지 않았다. `input_sent`를 성공으로 간주하지 않고
  후속 화면을 확인했다. 직원 이름 영역을 눌렀을 때 이동·제압이 시작됐다.
- 조우 설명에서 클릭 후 진행이 보이지 않아 스페이스를 시험했으나 설명 단계는 바뀌지 않았다.
  대화창 오른쪽 진행 영역을 클릭한 뒤 실제 이동이 재개되는 것을 확인했다.
- 패닉 회복 단계에서 지도 드래그로는 진행되지 않았다. 강조된 제압 패널에서 에바와 타샤를 각각 선택하자
  `제압중` 표시와 이동이 나타났고, 이후 회복 성공 안내로 넘어갔다.
- 게임 설명에서 일시정지 중 명령을 내리면 안정적이라는 점을 배웠다. 느린 판단 시간의 영향을 줄이는 데 활용할 수 있다.
- UI 텍스트에는 화면 뒤에 가려진 정보도 섞인다. 이미지와 대조하고, 같은 순간의 JSON/PNG라고 가정하지 않는다.

## 개발 오류와 플레이 경험의 구분

첫 가상 명령은 Windows 줄바꿈(CRLF) 때문에 거절됐다. 전송을 LF로 고친 뒤 새 판단으로 다시 실행했다.
공유 파일을 교체하는 순간 읽기가 거절되는 오류도 관찰했다. 읽기에만 짧은 제한 재시도를 추가했다.
이는 플레이어의 게임 지식과 구분되는 도구 개발 기록이다.
입력 경로를 조사한 managed 코드의 내용은 공략 지식으로 가져오지 않았다.

최종 빌드에서는 가상 포인터 이동 때 OS 커서와 전경 창이 그대로였다.
가상 D 1500ms 유지 중 물리 D는 눌리지 않았고, W 유지 도중 입력 중지를 적용하면 해제됐다.
실제 UI 입력과 관찰의 MCP 왕복 및 같은 결정 ID 재요청 무재실행도 확인했다.
이 최종 입력 시험은 튜토리얼 완료 이후 타이틀에서 수행한 개발 검증이다.
