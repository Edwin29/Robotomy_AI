# 0000 — 기록과 대화의 합성 예시

**개발 스크립트가 만든 연동 검증 예시입니다. LLM 판단도 실제 로보토미 플레이도 아닙니다.**
질문/답변 역시 스크립트가 생성했으며 실제 사람과의 대화를 재현한 것이 아닙니다.

## 실행 전 판단과 결과

첫 선택은 모의 `work`였다. "모의 작업의 결과를 관찰한다"고 기록한 뒤 실행했다.
합성 상태에서 에너지는 0에서 10, 체력은 100에서 80으로 바뀌었다.
이 변화는 테스트 구현의 결과이며 로보토미의 규칙을 의미하지 않는다.

## 회고와 대화

"모의 작업 후 체력이 감소했다"는 회고와 "로보토미의 규칙으로 일반화할 수 없다"는
불확실성을 따로 남겼다. "왜 다음 행동을 바꿨어?"라는 예시 질문에 결과/회고 ID를
근거로 답변했다. 다음 `rest` 판단은 해당 회고 ID를 참조했다.

휴식 후 합성 체력은 80에서 95로 바뀌었고, 행동 예산 2회에 도달해 세션이 종료 조건에 들어갔다.
이 스크립트의 행동 변화는 학습의 증거가 아니다. 검증 대상은 기록 사이의 연결이다.
