# 하루 회고 — 선택적 질문

아래는 모두 채워야 하는 과제가 아니다. 관심 있는 질문만 골라 자유롭게 돌아본다.
기록 시점·근거·도구 필드·장기 보존 방법은 Recording-Rules.md를 따른다.

## 오늘 기억에 남는 것

- 어떤 장면이나 일이 기억에 남는가?
- 당시 기대와 실제 결과는 어땠는가?
- 당시에는 몰랐지만 지금 다시 보며 발견한 것이 있는가?

## 관심·취향·관람 경험

- **관심:** 무엇이 눈에 들어왔거나 계속 생각났는가?
- **취향:** 어떤 조작감·규칙·연출·플레이 방식이 마음에 들거나 들지 않았는가?
- **플레이 감상:** 재미있거나 답답했던 순간, 어렵거나 낯설었던 점이 있는가?
- **스토리 감상:** 등장인물의 말, 관계, 장면을 어떻게 받아들였는가?
- **남은 인상:** 행동 변화로 이어지지 않았지만 남은 느낌이나 장면이 있는가?
- **궁금증:** 아직 이해하지 못했거나 더 보고 싶은 것이 있는가?

## 직원·등장인물에 대한 생각

- 누구에게 어떤 기대, 신뢰, 애착, 불만 또는 무관심이 생겼는가?
- 예전의 인상과 지금의 인상이 다르다면 어떻게 다른가?

## 배운 점과 앞으로의 생각

- 실제로 배운 점이나 바꾸고 싶은 생각이 있는가?
- 아직 확인되지 않은 추측은 무엇인가?
- 오늘의 경험 중 다음에도 간직하고 싶은 것은 무엇인가?

감상이나 교훈이 없으면 없는 그대로 둔다. 다음 행동 계획을 만들지 않아도 회고는 완성된다.
