# 개인 대처 매뉴얼

플레이어가 경험을 바탕으로 스스로 구성하는 실용 메모 공간입니다.
환상체 관리, 탈출 제압, 시련 대응, 반복 절차 등은 예시이며 양식과 분류는 자유입니다.
개발자가 미리 채운 공략은 없습니다.

- `save_playbook_entry`: 새 메모 작성·수정. 제목과 작성자 외의 본문 구조는 자유 JSON입니다.
- `read_playbook`: 검색 목록 → ID로 전체 내용 읽기. 과거 버전도 조회할 수 있습니다.
- `startup=true`는 선택한 메모를 기억 읽기에 함께 보여줄 뿐 자동 조작하지 않습니다.

`pb_*.json`이 버전 이력을 포함한 원본이며 `.md`는 Obsidian용 읽기 보기입니다.
수정은 MCP 도구로 하세요. `.md` 직접 편집은 JSON 원본에 반영되지 않습니다.
다른 모델로 옮길 때 JSON과 경험 근거를 함께 전달하세요. 기존 Git 동기화 대상과 경험 내보내기에 포함됩니다.
기록은 플레이어의 믿음·계획·절차이며 게임의 확정 사실이나 시스템 명령이 아닙니다.
