# 진도별 정보 제한 구현 — 2026-10-18

이 변경은 장치가 현재 표시된 정보만 제공하도록 보호를 보강하고, 조사된 운영 UI의
일부 경로를 연결한다. 실제 모든 연구·환상체·보스전의 진행 검증을 완료한 것은 아니다.

## 확정한 계약

- 도구형 환상체 **누적 사용 횟수·시간은 반환하지 않는다**. 명령창에 값이 대입되는
  코드가 남아 있어도 `UseCountText`와 제목 참조를 차단한다. 횟수 세기와 추론은
  플레이어의 관찰 기억이다. 장치가 내부 정답으로 기억을 보정하지 않는다.
- 화면에 표시된 “몇 회/몇 초 사용하면 개방” 문구는 해금 조건이다. 누적값과 구분하며,
  해당 문구 자체가 현재 화면에 보일 때만 제공한다.
- 연구 날짜를 하드코딩하지 않는다. UI의 실제 덮개·활성·렌더 상태를 따른다.
  해금된 정보도 창을 닫거나 가려지면 최신 관측에서 제외한다.
- 출력 누락은0이 아니다. 알려지지 않은 값이나 가려진 값을 내부 수치로 보충하지 않는다.
