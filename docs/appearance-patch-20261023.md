## Lab 실행 검증

실제 11일차 준비 화면에서 운영을 시작하고 즉시 일시정지한 별도 게임에서 검사했다.
게임 논리/세이브를 변경하지 않는 Lab 전용 fixture가 실제 Resources 프리팹을 표시한다.
검증용 프리팹의 배치·정렬 순서는 화면 대조를 위해 바꾸었다. 실제 환상체 기믹의 성공 플레이와 구분한다.

- 실제 초상 BufRenderer 아이콘이 화면에 있을 때 marks로 제공되고, 숨김/화면 밖에서는 빈 목록.
- actual observe_player의 직원 행에서 표식을 수신하고, 별칭을 붙인 뒤 다음 diff에서 같은 ID의 별칭 수신.
- YouMustHappy의 활성 spriteYes / spriteNo에 따라 YES / NO를 구분하고 화면 밖에서 제외.
- 일반 Lab 장면에서도 기존 직원/엔티티·방 상태와 appearance가 함께 제공됨.
- 처리 시간: 일반 장면 11개 관찰 행, 86개 표본에서 appearance_ms 중앙값 0.207ms,
  p95 0.267ms, 최대 0.328ms. 모델/앱 왕복, 전체 UI·motion·PNG 비용을 포함하지 않는다.
  같은 표본의 motion_ms 중앙값은 21.774ms, UI는 23.823ms였다. 전체 실시간 성능 개선으로 과장하지 않는다.

초기 fixture가 숨겨진 게임 객체의 depth를 따라 화면 밖에 놓이는 문제는 fixture 위치를
확인된 직원 UI의 투영 depth로 바꾸어 수정했다. 이후 BC7 배제와 캐시 포화를 실제로 확인해
표시 수집 코드도 보완했다. 이 시행착오와 성공 결과를 분리하여 보존한다.

추가 표시 대조:

- 오늘의 표정: 실제 FeelingState 표시 전환 0~4에서 서로 다른 외형 ID 5개.
- 웃는 시체들의 산: Level1 걷기/공격은 같은 외형 ID와 서로 다른 동작 ID,
  Level2는 별도 외형 ID. 걷기를 다른 폼으로 오인하지 않았다.
- 아무 것도 없는: 실제 Puppet2D의 Lv1/알/Lv2 세 몸체를 구분했다.
  Spine 공통 경로만으로는 수집되지 않아 실제 NothingAnim 표시 가지를 연결했다.
- 증오의 여왕: 실제 Hero 메시가 1,418 정점·41 서브메시인 것을 확인했다.
  기존 서브메시 32개 제한을 제거하고 정점/전체 삼각형 상한은 유지했다.
  로비 안에 배치한 두 몸체를 스크린샷과 대조했고 서로 다른 외형 ID를 받았다.
  화면 밖으로 옮기면 크리쳐 행이 사라지는 것도 확인했다.
- 특수 렌더링 경로 검증 중 fixture의 원래 Z 배율을 보존해야 함을 확인했다.
  또한 화면 밖 시설 배경에 겹쳐 배치된 프리팹을 픽셀 대조 근거로 삼지 않고
  실제 로비 안으로 옮겨 다시 대조했다. 임의의 가림 조합 전체를 검증한 것은 아니다.

위 시간 측정은 Puppet2D 경로 추가 전의 일반 장면 수치다. 모든 폼이나 다수 적이 등장한
전투의 성능 상한으로 사용하지 않는다. 본게임 적용과 실제 기믹 플레이 검증은 별도 단계다.

종료 확인: 검증용 게임은 정상 종료했고, fixture를 포함하지 않은 일반 Lab DLL을 다시 빌드했다.
본게임 PID 138248은 유지되었다. 원본/본게임/Lab의 `.dat` 각각 5/3/3개를 시작 전 해시와
대조해 전부 동일함을 확인했다(`save-final.json`). 본게임의 소스와 DLL은 배포하지 않았다.

## 정보 경계와 한계

이 기능은 보이는 차이를 재식별하는 장치다. `상태N`은 내부 단계/감정의 정답이 아니다.
플레이어가 기록한 별칭·설명도 게임이 확인한 효과가 아니다. 상태 전환의 원인과 결과는 별도 관찰해야 한다.
모션 태그가 공통이라는 가정 대신 실제 현재 표시 동작을 식별한다.
변화가 샘플 간격보다 빠르면 중간 상태가 누락될 수 있다. 화면 관찰값으로 미래 입력의 타이밍 성공을 보장하지 않는다.
임의의 모든 파티클, 위장 인물의 정체, 모든 보스 마스킹은 검증 범위에 포함되지 않는다.

로컬 상세 증거는 `.robotomy/appearance-work/`의 evidence, runtime-alias.json, performance.json,
texture-formats.json, unittests-final.txt, mcp-smoke.txt에 있다. 플레이어 경험 저장소에는 연구용 증거를 넣지 않았다.
