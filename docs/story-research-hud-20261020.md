# 스토리·연구창·직원 바 패치 — 2026-10-20

본 플레이용 DLL과 Python, 플레이어 지침에 적용했다. 설치 백업은
`.robotomy/backups/20261020-story-hud-research`이며 게임 자산·세이브는 Git 대상이 아니다.

## 실제 게임 구조

- `StoryDialogueUI.dialogueNameUI`, `DialogueDisplay`의 실제 Text, 편지/내레이션 Text만 읽는다.
  `_dialogue`, 스크립트, 미래 대사와 이야기 로그는 읽지 않는다.
- 스토리는 MainCamera에 연결된 Canvas를 사용한다. 운영 화면의 월드 UI 거부 규칙을
  그대로 적용하면 이름과 대사가 전부 빠졌다. 지정된 스토리 Text에 한해 이 제약을
  해제하고 활성화·알파·마스크·화면 경계·외부 덮개 검사는 유지했다.
- `DialogueDisplay.Init`이 대사 Text 하위에 NextGuide를 생성한다.
  이 대기 아이콘의 깜박임은 새 이야기 화면을 의미하지 않으므로 화면 변경 키에서 제외한다.
- `ResearchWindow`와 `ResearchPanel`의 표시 Text에서 연구명·효과·설명을 읽는다.
  연구 모델의 숨겨진 효과/수치나 미표시 연구 목록을 반환하지 않는다.
- 연구는 클릭 선택이 아니라 `Drag`→`Drop` 방식이다. 투명한 히트 영역의 알파 대신
  실제 EventSystem 수신 대상을 확인해 시작점/놓을 점을 제공한다.
  `DragExchanger`, `DragOverDrop`의 공개 dropScript 연결도 확인한다.
- 연구 카드의 기울기는 정상 UI 디자인이다. 해당 패널에 한해 회전 거부를 해제한다.
  확인 화면에는 선택된 카드만 제공하며 드래그 도중에는 텍스트 제공을 쉬어간다.

## 스토리 캡처 및 전달

- 대사/화자/선택지의 표시 문자열과 활성 이미지 sprite 변경이 캡처 신호다.
  변경 중에는 기존 약 1 Hz로 제한한다.
- 대사가 있는 대기 화면은 약 3초마다 보완 캡처한다. 대사가 없는 전환 화면은 약 1 Hz다.
  이는 영상 전체 프레임 보존이 아니다. 짧은 비텍스트 연출이 모두 보존된다고 보장하지 않는다.
- 동일 픽셀이면 PNG 재인코딩/파일 쓰기를 생략한다. 단순 대기 확인은 과거 버퍼를 채우지 않는다.
  sprite가 아닌 셰이더/영상 변화는 보완 캡처로 최신 화면에 반영되며, 모두 개별 역사 항목으로 저장하지 않는다.
- `frame_after`는 고정 경로의 캡처 요청을 보내 즉시 새 픽셀을 요청한다.
  게임 입력/일시정지/대사 진행을 일으키지 않는다.
- PNG mtime 대신 세션·PID·장면·해시가 검증된 캡처 메타데이터 시각으로 최신성을 판단한다.
  메타데이터가 오래됐거나 해시가 불일치하면 여전히 거부한다.
- `game_input(command=..., include_frame=true)`는 한 입력의 결과와 후속 전체 화면을 함께 반환한다.
  입력 후 별도의 화면 도구 호출을 줄인다. 글자가 모두 나온 것을 보장하지 않으며 미관람 대사를 자동으로 넘기지 않는다.
- `wait_for_event`는 스토리 장면에서 시설 사건 대기 대신 즉시 안내를 반환한다.

## 검증 결과와 범위

- 실제 검증 게임의 정보팀 연구 카드 3개에서 표시된 이름/효과/설명 및 좌표 추출을 확인했다.
  제공된 드래그 좌표로 확인 화면까지 이동했다. 연구 확정은 하지 않았다.
  테스트용 연구창은 별도 진단 컴포넌트가 게임의 실제 Init/SetActive로 열었다.
  보상 해금 흐름을 실제 플레이로 완료한 검증은 아니다. 진단 컴포넌트는 배포 DLL에서 제거했다.
- 실제 StoryViewer 1일차 장면에서 `앤젤라`와 `안녕하세요 X.`가 분리되어 추출됐다.
  대기 약 10초 동안 과거 버퍼는 3개로 유지됐고 보완 캡처는 약 3.1초 간격이었다.
- 입력 후 캡처 요청부터 PNG 반환까지 한 표본은 약 0.17초였다.
  전체 모델 추론/클라이언트 지연을 포함한 수치나 평균 플레이 속도 개선율이 아니다.
- HP/SP 검증은 [직원 바 검증](employee-hud-bars-20261020.md)을 따른다.
  해금되지 않거나 화면에 표시되지 않는 바는 null이며 내부 정확 수치로 대체하지 않는다.
- 회귀 테스트 261개 및 MCP stdio smoke 통과. 새 옵션과 이미지 동시 반환,
  스토리 사건 대기 회피, 연구 좌표 파싱, 재확인된 이미지의 최신성/만료 경계 포함.
- 원본 세이브/환경 무결성 검사 통과. 본게임 저장 파일 6개는 배포 직전/직후 동일 해시.
