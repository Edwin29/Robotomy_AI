## 제공 정보

`console.hazards`에 다음 표시값을 제공한다. 변경된 하위 항목은 `change_summary.priority_changes`에 먼저 나온다. compact 관찰에도 유지되며, 가려지거나 사라진 값은 null/빈 목록으로 철회한다.

| 항목 | 의미와 출처 |
| --- | --- |
| `ordeal.color`, `stage`, `label` | 실제 활성 예고 Text의 색과 문구. `녹빛 여명`, `자색 정오`, `핏빛 어스름`, `호박색 자정` 형태. 여명·정오·어스름·자정 표기는 게임 화면을 따른다. |

생산자는 기존 약 100ms 표본 주기로 갱신한다. LLM 추론 중에도 생산은 계속된다. 이 패치는 강제 알림/모델 호출을 추가하지 않으므로 플레이어는 다음 빠른 관찰에서 변경을 받는다. 실시간 반응 시간을 100ms로 보장한다는 뜻은 아니다.

## 게임 구조 근거

- `EnergyController.SetOverLoadOrdeal`: 예고가 있으면 방 수를 숨기고, 단계 문구와 `OverloadColored`의 색을 표시한다. 실제 직렬화된 참조에 단계 Text도 색 적용 대상으로 포함되어 있다.
- `SetOverloadGauge`: 실제 레이아웃 자식 Image가 총 칸 수이며 채워지지 않은 칸은 alpha 0이다. 모델 카운터를 읽지 않고 이 표시 레이아웃과 현재 색을 읽는다.
- `IsolateOverload.SetTimer`: `CeilToInt`로 만들어진 `timerText`만 읽는다. 정상 UI 갱신은 `IsolateRoom`이 담당한다.
- 기본 WorldSpace 방 Canvas에는 `worldCamera`가 비어 있다. 실제 Canvas 레이어를 그리는 카메라로 화면 좌표를 계산한다. 동적으로 만들어지는 게이지 자식의 Default 레이어를 카메라 가시성 기준으로 삼지 않는다.
- 이 버전 Unity UI의 `MaskUtilities`와 `MaskableGraphic`에 맞춰 sorting-override Canvas 경계에서 부모 마스크 적용을 끊는다.

## 카메라 중심의 판정

사용자의 설명에 맞춰 방의 프레임·배경·입력용 WorldSpace Canvas를 독립적인 화면 가림막으로 취급하지 않는다. 같은 표시 면 안의 장식을 검사하느라 정상 타이머가 누락되던 처리를 제거했다. 시도했던 장식별 투명도/허용 비율 계산은 최종 패치에 포함하지 않았다.

방 정보의 핵심 조건은 활성 표시, 카메라 안의 화면 좌표, 실제 UI 클리핑, 지원되는 화면 효과다. 별도 화면 메뉴는 화면 UI 계층에서 처리한다. 예소드의 `CameraFilterPack_Pixel_Pixelisation` 등 정보 훼손 효과는 일반 화면 허용 목록에 넣지 않았다. **예소드 보스전 자체를 실행해 검증한 것은 아니다.** 해당 렌더 경로 차단은 코드로 확인했다.

## 검증 범위와 결과

검증용 실제 게임 UI에 표시값을 설정하고 렌더된 PNG와 추출 JSON을 함께 저장하는 장치를 사용했다. 이는 자연 진행으로 16종 시련을 발생시켰다는 뜻이 아니다. 테스트 장치는 게임 모델·세이브를 쓰지 않으며 표시값을 원복한다. 장치 코드는 배포 패치에서 제외했다.

- 자연 표시: 단계 I, 게이지 0/5, 대상 1방 일치.
- 렌더된 표시 조합: 네 색 × 네 단계, 총 16개 label 일치.
- 표시 fixture: 단계 III, 게이지 2/6, 대상 3방 일치.
- 방 표시: `T-02-99`, `30초`, 화면 좌표 반환. 화면 밖으로 옮기면 타이머 목록에서 제외.
- 전체 검은 가림막: 색·단계·게이지·방 수가 null, 타이머는 빈 목록. 제거/원복 후 정상 정보 복구.
- 실제 렌더 결과를 임시 데이터 루트의 LiveReader에 통과시켜 compact diff 선두, 변경값만 반환, 가림 시 철회를 확인했다. 5회 로컬 호출은 5.53~13.31ms였다. 이는 MCP 전송/LLM 추론을 포함한 종단 지연이 아니다.
- 누적 패치 Python 회귀 테스트 188개 통과. 별도 임시 루트 MCP stdio smoke 통과. 실제 게임 참조 DLL을 사용한 배포용 C# 조합 컴파일 통과.
