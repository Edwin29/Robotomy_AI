# 관찰 상단 변경 요약 원안

구현 완료. 현재 동작과 제한은 [observation-diff.md](observation-diff.md)를 따른다.

목적: 이미 읽은 상태를 매번 다시 해석하는 비용을 줄인다. 게임기가 해석/공략 판단을
추가하지 않고, 플레이어에게 실제 제공한 공개 정보 사이의 차이만 계산한다.

MCP 응답 맨 앞에 change_summary를 배치한다. 영상 우상단에 글자를 합성하는 방식은
원본 CCTV 화면을 가리거나 영상 재처리 비용이 생기므로 기본안으로 삼지 않는다.
관찰 웹페이지에는 별도 우상단 패널로 표시할 수 있다.

- 비교 기준: 서버가 마지막 수집한 프레임이 아니라 해당 플레이어가 마지막으로 받은 관찰.
- base observation ID / current ID / 경과 시간 / 비교 가능 여부 명시.
- 추가, 값 변경, 현재 관찰에서 사라짐, 장면 전환, 이벤트 누락/초과 표시.
- 사라짐을 사망으로 추론하지 않는다. 가려지면 과거 위치/HP를 현재 정보처럼 재노출하지 않는다.
- 최초 관찰·프로세스 교체·기준 유실 시 full_required. 숫자 변화와 이야기/선택지 변경을 구분.
- 시간/프레임 번호/샘플 시각 자체의 변화는 요약에서 제외. 변경 없음은 화면 전체가 동일하다는
  뜻이 아니라 비교한 구조화 정보에서 차이를 찾지 못했다는 뜻이다.
- 동일 응답 아래 full을 계속 붙이면 전송량과 모델 입력 토큰은 그대로다. compact 옵션과
  필요한 전체 상태 조회를 별도로 제공해야 비용까지 줄일 수 있다.
- 기록에는 실제 제공한 diff와 base ID를 남겨 나중에 당시 정보 범위를 복원한다.
- 원본 스크린샷/스토리 관람은 유지한다. 이벤트 사이의 짧은 변화는 별도 버퍼와 함께 다룬다.
