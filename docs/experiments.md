# 무작정 클리어 goal을 주는 실험에 대한 제안

## 판단

탐색 기준선으로는 가치가 있다. 다만 처음부터 장기 실행하면 게임 플레이보다
조작 수단 발견/개발/오류 복구에 시간을 쓸 수 있다. 그 결과도 유용하지만 다른 능력을 측정한다.

두 실험을 구별한다.

- **도구 발견 실험:** 접근 가능한 환경에서 무엇이 필요한지 스스로 찾는가. 결과는 도구/연결 능력의 기록.
- **플레이 실험:** 검증된 조작 인터페이스와 기록 장치를 제공하고 전략을 정해주지 않는다.
  결과는 관찰·선택·실패·수정 과정의 기록.

사용자의 목적에는 두 번째가 주 실험으로 적합하다. 방법을 자유롭게 두는 것은
공략을 제공하는 것과 다르며, 조작 인터페이스 제공은 마우스/키보드를 제공하는 것에 해당한다.

## 첫 실제 플레이의 범위

실제 연결 수용 기준 통과 후, 테스트 세이브와 명확한 종료 조건으로 짧게 시작한다.
최종 목표는 클리어로 두되 첫 회차는 예를 들어 주요 판단 20회까지 관찰한다.
진행, 시행착오, 도구 실패, 사용자 개입을 각각 구별한다. 실패를 무한 재시도하지 않는다.
현재 행동 예산은 합성 테스트에 구현되어 있다. 실제 플레이 시간/비용 제한은 추가 구현이 필요하다.

기술적인 게임 일시정지와 실험 실행기 일시정지를 구별한다. 실게임에서 정지 제한/불이익이 있으면
게임 규칙을 우회하지 않는다. LLM 호출 대기시간을 게임 정지로 보상할지는 실험 조건에 기록한다.

## 공략 없이 플레이하는 역할

공략/위키/정답 데이터/디컴파일 결과를 플레이 중 의사결정에 사용하지 않는다.
게임 화면/정상 UI/튜토리얼과 자기 플레이 기록에서 가설을 세운다.
LLM의 학습된 기존 지식은 완전히 제거할 수 없으므로 “완전한 무지”를 입증했다고 하지 않는다.
인터넷을 물리적으로 끊는 것이 프로젝트 목적은 아니다.

## 판단 관찰

모든 프레임의 설명 대신 중요한 결정 경계마다 짧은 목표·이유·예상·불확실성을 남긴다.
실행 전의 판단과 결과를 본 후의 회고를 분리한다. 질문에 답할 때 해당 사건을 인용한다.
질문이 전략에 영향을 줄 수도 있으므로 사용자와 대화한 회차를 무개입 회차와 구별한다.

## 모델 이전 비교

동일한 관찰 조건과 비슷한 자료량/호출 예산으로 새 모델을 비교한다.

1. 기억 없음
2. 정리된 규칙/요약만 제공
3. 당시 관찰·예상·실패·판단 변화의 기록 제공

클리어 외에도 이전 실패 반복, 새로운 상황에서의 적응, 근거 없는 경험 주장,
사용자 경험을 설명하는 정확도, 비용과 지연을 측정한다.
