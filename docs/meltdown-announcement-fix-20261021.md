# 폭주 안내 이벤트 누락 수정

폭주 안내 Text에 일반 가림 필터를 적용하던 경로를 제거했다. 게임의 SetOverLoadUI postfix에서 실제 안내 UI가 활성화되고 문자열이 존재하면 호출당 한 번 이벤트를 생성한다. 원본 메서드가 안내를 생략하는 E4 분기는 동일하게 생략한다. 상한 단계에서도 반복 폭주를 구별하며 단계 변경 추정은 추가하지 않는다.

2026-10-21 본 플레이 DLL 적용 및 정상 재시작. 원본 저장 파일29개와 플레이 저장 파일6개 해시 동일. 백업은 `.robotomy/backups/20261021-meltdown-announcement/`. 빌드 및 관련 Python 테스트15개 통과. 이번 배포 확인에서는 실제 폭주를 유발하지 않았으므로 게임 내 재발 방지 실증은 다음 플레이에서 확인해야 한다.
