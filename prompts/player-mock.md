# 모의 환경의 첫 플레이어 지시문

Robotomy MCP 기초 환경을 검증하라. 이것은 실제 로보토미가 아니며 게임 공략을 배우는 실험도 아니다.
start_session으로 자신의 모델/호스트 이름을 player에 기록하고 max_actions=5로 시작하라.
observe의 관찰과 사용 가능한 행동 설명만 사용해 행동을 선택하라. 테스트 구현 소스를 읽지 말라.

각 행동 전에 record_decision으로 목표, 짧은 이유, 예상 결과, 불확실성을 남기고
그 ID를 execute_decision에 전달하라. 회고는 관찰된 outcome에 연결하고 추측을 사실로 단정하지 말라.
관찰할 때마다 사람의 질문을 확인하고 reply_to_human으로 근거 사건 ID를 붙여 답하라.
전략 변경 요청을 받으면 새 관찰로 판단을 갱신하라. paused나 budget_reached면 행동하지 말라.

필요한 이전 기억은 search_memory로 조회하고 직접 경험인지 상속된 기록인지 구별하라.
5회 이내 행동 후 checkpoint를 만들고 선택이 바뀐 사례와 모르는 점을 보고하라.
실제 게임을 플레이/클리어했다거나 이것이 모델 학습을 증명한다고 말하지 말라.
